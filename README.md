# ECHO — *the signal that was never sent*
**Entangled Minds: The Quantathon · Qubits Qrew, NED University of Engineering & Technology**
**Investigator:** Amna Shahzad (Roll No. CT_24018, Section B, AI)

> **Verdict:** ECHO never sent a message. Dr. Zara Mahmud mistook an *echo* (correlation) for a *voice* (a signal). Her "random" trigger was a coin tuned to 70/30, and the only faster-than-light part of the story was a classical channel hidden inside her own machine.

## Modules

| Module | Type | Depth | Result | What it proves |
|---|---|---|---|---|
| 01 The Gatekeeper | Mandatory | 🥇 | X → 1; H → 50/50; H·H → 0; vault `101` | Something that looks random can hide certainty |
| 02 The Honest Coin | Stretch | 🥇 | Seed Ry(1.159): P(1) = **0.300**, 17.6σ from fair | ECHO's trigger was a tuned coin, not a fair one |
| 03 The Two Observers | **Mandatory** | 🥇 + CHSH | Agreement in Z: pair 100% = secret 100%. In X: pair 100% vs secret 51%. Bob always 50/50 | Correlation, never communication |
| 04 The Erased Measurement | Stretch | 🥇 | XHH → 1, HXH → 0; rulebook correct on 120/120 sequences; re-reading never changes a result | Only the *first* measurement erases |
| 05 The Damaged Message | **Mandatory** | 🥇 | Last word: **ECHO**; two flips gives "DCHO"; corrects 1 / notices 2 | Repetition codes work for bits; qubits need parity codes, because of no-cloning |
| 06 The Impossible Claim | Stretch (**declared**) | 🥇 | 100% with 2 classical bits, 50% without; ρ_B = I/2 | Teleportation can't be faster than light |

## Run it
- **Colab:** go to [colab.research.google.com](https://colab.research.google.com), choose *File → Open notebook → GitHub*, paste this repository's URL and open `ECHO_Investigation_Notebook.ipynb`. Then click *Runtime → Run all* (about 1 minute). The first cell installs `qiskit==2.6.0` and `qiskit-aer==0.18.0` if they aren't already there; no restart is needed.
- **Locally:** `pip install -r requirements.txt jupyter`, then open the notebook and run all cells.
